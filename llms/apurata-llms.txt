# Apurata

> Apurata (Tecno Creditos S.A.C.) is a Peruvian fintech, authorized by Peru's SBS, offering fast online personal loans and the aCuotaz "buy now, pay later" installment product for e-commerce merchants. Merchants integrate installment checkout via a REST API, webhooks, and prebuilt payment-gateway plugins; Apurata pays the merchant upfront while the customer repays in up to 8 installments.

## APIs
- [aCuotaz POS REST API](https://docs.apurata.com/POS/rest_api/): Create and manage installment orders, refunds, and checkout widgets. Base URL https://apurata.com.
- [aPagos REST API](https://docs.apurata.com/apagos/rest_api/): Apurata's aPagos payments product.
- [Samsung Finance+ aCuotaz API v1](https://docs.apurata.com/samsung_finance_plus/sfplus/): Financing application + credit prefetch API for the Samsung Finance+ program.
